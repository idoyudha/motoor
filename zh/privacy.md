## 我们是谁

Motoor 是由独立开发者 **{{ dev.name }}**（以下称“我们”）开发和发布的应用。我们对 Motoor 如何处理你的信息负责。你可以通过 [{{ dev.email }}](mailto:{{ dev.email }}) 联系我们。

本政策适用于 Android 和 iOS 上的 Motoor 应用、Motoor 创建的分享页面以及本网站。

## 我们收集哪些信息

**你的账户。** 添加车辆需要使用 Google 账户登录，在 iOS 上也可以使用 Apple 账户登录。我们会通过登录获得你的姓名、电子邮件地址和账户 ID。我们永远看不到你的 Google 或 Apple 密码。

**你的记录本。** 你在 Motoor 中输入的所有内容：

- 车辆：品牌、型号、类别、名称、车牌、年份、里程读数、备注和照片
- 加油和充电记录、保养、费用、地点和备注
- 提醒及其计划
- 你附加的收据、扫描件和其他文件
- 你的设置，例如单位、货币、语言和主题

**你的设备。** 推送通知令牌（用于将提醒和通知发送到你的手机），以及平台（Android 或 iOS）。

**购买信息。** 由 Google Play 或 App Store 报告的你是否拥有有效的 Premium 订阅。

{% if p.crash_reporting != "" %}**崩溃报告。** 应用崩溃时的技术详情（见下文）。
{% endif %}
{% if p.analytics != "" %}**使用统计。** 哪些功能被使用（见下文）。
{% endif %}

**你发给我们的电子邮件。** 你的邮箱地址以及你所写的内容。

## 你的记录本存放在哪里

你的记录本存储在你的手机上，位于 Motoor 的私有存储空间中，因此应用无需联网即可使用。

它还会**自动备份**到我们在 Google Cloud 上的服务器，位于 **{{ t.privacy.data_location }}**。所有已登录用户（无论是 Free 还是 Premium）都会进行备份，且没有关闭备份的开关：Motoor 正是通过备份在你登录新手机时恢复你的记录本。备份内容包括你的记录、附件和收据。

数据在你的手机与我们的服务器之间传输时经过加密，在 Google Cloud 上存储时也经过加密。只有你能通过应用查看你的记录本。我们仅在你请求帮助或我们需要修复故障时才会访问存储的数据。

## 收据扫描（Premium）

当你扫描收据时，Motoor 会从中读取总金额、日期和地点，省去你手动输入的麻烦。在保存任何内容之前，你会逐项核对。里程绝不会从收据中读取。

- **尽可能在你的手机上完成。** 如果你的手机内置了能读取收据的模型，Motoor 会使用它，识别在设备上完成。
- **否则在我们的服务器上完成。** 图片或 PDF 会上传到我们的服务器，服务器将其发送至位于 {{ t.privacy.scan_location }} 的 **Google Cloud 上的 Google Gemini 模型**。我们使用的是 Google 的付费服务，其条款不允许 Google 使用这些数据训练其模型。提取出的字段会返回到你的手机。

无论哪种方式，扫描件都会作为附件与该记录一起保存，并像记录本中的其他内容一样被备份。

## 分享和转让车辆（Premium）

**分享历史**会创建一个链接和二维码，指向一个只读网页，其中包含该车辆的记录、日期、里程读数和总计。页面不显示任何账户信息。任何拥有该链接的人都可以打开它，直到链接在 24 小时后过期或被你撤销。

**转让所有权**会创建一个一次性代码，24 小时后过期。第一个打开它的 Premium 用户将获得该车辆及其历史和收据，你会看到对方的姓名和领取时间。你的副本将变为只读。

## 购买

如果你购买 Premium，付款完全由 **Google Play** 或 **Apple App Store** 处理。我们永远看不到你的银行卡或付款信息。应用商店只会告诉我们你是否拥有有效的购买，以便在你的其他设备上解锁和恢复 Premium。

## 还有谁会处理你的数据

我们不出售你的个人信息，也不会为广告目的分享这些信息。以下服务提供商代表我们处理数据，仅用于运行 Motoor：

| 服务提供商 | 用途 | 处理的数据 |
|---|---|---|
| Google Cloud | 在 {{ t.privacy.data_location }} 托管我们的服务器、数据库和文件存储 | 你的账户和记录本备份 |
| Google Cloud (Gemini) | 读取无法在你手机上识别的收据 | 你扫描的收据 |
| Firebase Authentication (Google) | 使用 Google 或 Apple 登录 | 姓名、电子邮件、账户 ID |
| Firebase Cloud Messaging (Google) | 发送推送通知 | 设备推送令牌 |
{% if p.crash_reporting != "" %}| {{ p.crash_reporting }} (Google) | 崩溃报告 | 崩溃的技术详情 |
{% endif %}{% if p.analytics != "" %}| {{ p.analytics }} (Google) | 使用统计 | 应用实例 ID 和功能事件 |
{% endif %}| Google Play、Apple App Store | 订阅和付款 | 购买状态 |

Firebase 服务由 Google 运营，可能会在印度尼西亚境外处理数据。货币换算所用的汇率来自我们自己的服务器；获取汇率时不会发送任何关于你的信息。

## Motoor 请求的权限

| 权限 | 原因 | 如果你拒绝 |
|---|---|---|
| 通知 | 在保养到期时提醒你 | 提醒仍会在应用内显示 |
| 相机 | 拍摄收据和车辆照片 | 你可以改为选择已有的照片或文件 |

Motoor 不会请求你的位置、通讯录、麦克风或通话记录权限。如果你开启生物识别锁，你的指纹或面容由你的手机进行验证；Motoor 永远不会接收这些信息。

## 你的选择和权利

根据印度尼西亚《个人数据保护法》（2022 年第 27 号法律）以及你所在地的类似法律，你有权访问、更正、删除你的个人数据，以及撤回同意。在 Motoor 中：

- **访问和复制：** 在 **设置 → 导出和备份** 中，将记录本导出为 CSV，或导出为附带收据的 PDF 保养历史。
- **更正：** 在应用中编辑任何车辆、记录或提醒，并在 **设置 → 个人资料** 中修改你的姓名。
- **删除：** 在应用中删除单条记录，或删除你的整个账户（见下文）。

如有其他需求，请发送电子邮件至 [{{ dev.email }}](mailto:{{ dev.email }})。

## 删除你的账户

打开 **设置 → 个人资料 → 删除账户** 并确认。如果你已不再使用该应用，也可以通过电子邮件请求我们删除；请参阅[支持页面]({{ '/zh/support/#delete-your-data' | relative_url }})。

- 你的账户会**立即被锁定**，所有分享链接和未完成的转让都会失效。
- 在 **{{ p.deletion_grace_days }} 天**内你可以改变主意：重新登录并选择**恢复**。
- {{ p.deletion_grace_days }} 天后，你的账户、记录本备份、附件、收据和扫描件将从我们的服务器上**永久删除**，你的登录账户也会被移除。我们灾难恢复备份中的副本将在之后的 {{ p.backup_expiry_days }} 天内过期。
- 删除账户不会取消你的订阅。请在 Google Play 或 App Store 中取消订阅，它们会保留各自的购买记录。

从手机上删除应用只会删除手机上的副本。你的备份会一直保留，直到你删除账户。

## 我们保留信息多长时间

| 信息 | 保留期限 |
|---|---|
| 你的账户和记录本备份 | 保留至你删除账户，之后再保留 {{ p.deletion_grace_days }} 天，然后删除（备份副本在其后 {{ p.backup_expiry_days }} 天内过期） |
| 你删除的单条记录、车辆或照片 | 立即从你的设备上删除，并在 90 天内从我们的服务器上删除 |
| 分享和转让链接 | 保留至 24 小时后过期或被撤销，之后作为记录保留，直到你的账户被删除 |
{% if p.crash_reporting != "" %}| 崩溃报告 | 最长 90 天 |
{% endif %}{% if p.analytics != "" %}| 使用统计 | {{ t.privacy.analytics_retention }} |
{% endif %}| 支持邮件 | 最后一封邮件后 12 个月 |

## 安全

手机上的记录本保存在 Motoor 的私有存储空间中，其他应用无法读取，你还可以添加生物识别锁。Motoor 通过互联网发送的所有内容都经过加密。分享和转让链接使用无法猜测的长随机代码，我们只存储每个代码的指纹。请使用 PIN 码、指纹或面容解锁来锁定你的手机，以保护其中的内容。

## 儿童

Motoor 面向拥有或照管车辆的人士，不针对 {{ p.min_age }} 岁以下的儿童。我们不会在知情的情况下收集儿童的个人信息。如果你认为有儿童向我们提供了信息，请发送电子邮件告知我们，我们将予以删除。

## 本政策的变更

如果我们更改本政策，我们会更新本页顶部的日期。如果某项变更影响我们收集的信息或处理信息的主体，Motoor 还会在变更生效前在应用内告知你。

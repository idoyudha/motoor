## 運営者について

Motoor は、独立開発者である **{{ dev.name }}**（以下「当方」）が開発・公開しているアプリです。当方は、Motoor におけるお客様の情報の取り扱いについて責任を負います。お問い合わせは [{{ dev.email }}](mailto:{{ dev.email }}) までご連絡ください。

本ポリシーは、Android および iOS 版の Motoor アプリ、Motoor が作成する共有ページ、および本ウェブサイトに適用されます。

## 収集する情報

**アカウント。** 車両を追加するには、Google、または iOS では Apple でログインします。このログインを通じて、お名前、メールアドレス、アカウント ID を受け取ります。Google や Apple のパスワードを当方が見ることはありません。

**ログブック。** お客様が Motoor に入力するすべての情報：

- 車両：メーカー、モデル、車種、名前、登録番号（ナンバー）、年式、走行距離の記録、メモ、写真
- 給油・充電の記録、整備、費用、場所、メモ
- リマインダーとそのスケジュール
- 添付したレシート、スキャン、その他のファイル
- 単位、通貨、言語、テーマなどの設定

**デバイス。** リマインダーや通知をスマートフォンに届けるためのプッシュ通知トークン、およびプラットフォーム（Android または iOS）。

**購入情報。** Google Play または App Store から報告される、有効な Premium サブスクリプションの有無。

## ログブックの保存場所

ログブックはお使いのスマートフォンの Motoor 専用ストレージに保存されるため、オフラインでもアプリを使えます。

また、**{{ t.privacy.data_location }}** にある Google Cloud 上の当方のサーバーに**自動でバックアップ**されます。これは Free・Premium を問わず、ログインしているすべてのユーザーに対して行われ、オフにする設定はありません。新しいスマートフォンでログインしたときに Motoor がログブックを復元するのは、このバックアップによるものです。バックアップには記録、添付ファイル、レシートが含まれます。

データは、スマートフォンと当方のサーバーとの通信中に暗号化され、Google Cloud 上での保存時にも暗号化されます。アプリを通じてログブックを閲覧できるのはお客様だけです。当方が保存データにアクセスするのは、お客様からサポートを求められた場合、または不具合の修正が必要な場合に限ります。

## レシートのスキャン（Premium）

レシートをスキャンすると、Motoor が合計金額、日付、場所を読み取るため、手入力の必要がありません。保存する前に、すべての項目をお客様ご自身で確認します。走行距離がレシートから読み取られることはありません。

- **可能な場合はスマートフォン上で。** お使いのスマートフォンにレシートを読み取れる内蔵モデルがある場合、Motoor はそれを使用し、読み取りは端末上で行われます。
- **それ以外の場合は当方のサーバーで。** 画像または PDF が当方のサーバーにアップロードされ、サーバーから {{ t.privacy.scan_location }} の **Google Cloud 上の Google Gemini モデル**に送信されます。当方は Google の有料サービスを利用しており、その規約により、Google がデータをモデルのトレーニングに使用することは認められていません。抽出された項目はスマートフォンに返されます。

いずれの場合も、スキャンは記録の添付ファイルとして保存され、ログブックのほかのデータと同様にバックアップされます。

## 車両の共有と譲渡（Premium）

**履歴の共有**では、車両の記録、日付、走行距離、合計を表示する閲覧専用のウェブページへのリンクと QR コードを作成します。アカウント情報は表示されません。リンクを知っている人は誰でも、24 時間後に期限が切れるか、お客様が取り消すまで、そのページを開くことができます。

**所有権の譲渡**では、24 時間で期限が切れる 1 回限りのコードを作成します。最初にそのコードを開いた Premium ユーザーが、履歴とレシートを含む車両を受け取ります。お客様には、相手の名前と受け取った日時が表示されます。お客様の手元のコピーは閲覧専用になります。

## 利用統計

Motoor は **{{ p.analytics }}** を使用して、アプリの利用状況を集計します。たとえば、車両の追加を完了した人数、最初の給油を記録した人数、Premium 画面を開いた人数と選ばれたプランなどです。これらの統計は、お名前やメールアドレスではなく、ランダムなアプリインスタンス ID に紐づけられ、ログブックの記録は含まれません。
{% endif %}

## 購入

Premium を購入する場合、支払いはすべて **Google Play** または **Apple App Store** が処理します。当方がカード情報や支払い情報を見ることはありません。ストアから当方に伝えられるのは有効な購入があるかどうかのみで、これにより Premium を有効化し、お客様のほかのデバイスでも復元できます。

## お客様のデータを取り扱うほかの事業者

当方は、お客様の個人情報を販売することも、広告目的で共有することもありません。以下の事業者は、Motoor を運営する目的に限り、当方に代わってデータを処理します：

| 事業者 | 役割 | 取り扱うデータ |
|---|---|---|
| Google Cloud | {{ t.privacy.data_location }} で当方のサーバー、データベース、ファイルストレージをホスト | アカウントとログブックのバックアップ |
| Google Cloud (Gemini) | スマートフォンで読み取れないレシートの読み取り | スキャンしたレシート |
| Firebase Authentication (Google) | Google または Apple でのログイン | 名前、メールアドレス、アカウント ID |
| Firebase Cloud Messaging (Google) | プッシュ通知の配信 | デバイスのプッシュトークン |
{% if p.crash_reporting != "" %}| {{ p.crash_reporting }} (Google) | クラッシュレポート | クラッシュの技術的な詳細 |
{% endif %}{% if p.analytics != "" %}| {{ p.analytics }} (Google) | 利用統計 | アプリインスタンス ID と機能のイベント |
{% endif %}| Google Play、Apple App Store | サブスクリプションと支払い | 購入状況 |

Firebase のサービスは Google が運営しており、インドネシア国外でデータが処理される場合があります。通貨換算の為替レートは当方のサーバーから取得しており、取得時にお客様に関する情報は一切送信されません。

## Motoor が求める権限

| 権限 | 理由 | 許可しない場合 |
|---|---|---|
| 通知 | 整備の時期をお知らせするため | リマインダーは引き続きアプリ内に表示されます |
| カメラ | レシートや車両を撮影するため | 代わりに既存の写真やファイルを選択できます |
| 写真とファイル | 手元の写真や PDF を添付するため | 代わりにカメラを使用できます |

Motoor が位置情報、連絡先、マイク、通話履歴へのアクセスを求めることはありません。生体認証ロックをオンにした場合、指紋や顔の認証はお使いのスマートフォンが行い、Motoor がそのデータを受け取ることはありません。

## 情報の利用目的

当方がお客様の情報を利用するのは、以下の目的に限ります：

- ログブックをスマートフォンに保存し、復元できるようバックアップするため
- リマインダーや通知を送信するため
- スキャンしたレシートを読み取るため
- お客様が求めた共有ページや譲渡を作成するため
- Premium を有効化・復元するため

{% endif %}- サポートのお問い合わせに回答するため

## お客様の選択と権利

インドネシアの個人データ保護法（2022 年法律第 27 号）およびお住まいの地域の同様の法律に基づき、お客様には、個人データへのアクセス、訂正、削除、および同意の撤回を求める権利があります。Motoor では次のように行えます：

- **アクセスとコピー：** **設定 → エクスポートとバックアップ** から、ログブックを CSV として、またはレシート付きの PDF 整備履歴としてエクスポートできます。
- **訂正：** アプリ内で車両、記録、リマインダーを編集でき、お名前は **設定 → プロフィール** で変更できます。
- **削除：** アプリ内で個々の記録を削除するか、アカウント全体を削除できます（下記参照）。

その他のご要望は、[{{ dev.email }}](mailto:{{ dev.email }}) までメールでご連絡ください。

## アカウントの削除

**設定 → プロフィール → アカウントを削除** を開き、確認します。アプリをお持ちでない場合は、代わりにメールでご依頼いただけます。詳しくは[サポートページ]({{ '/ja/support/#delete-your-data' | relative_url }})をご覧ください。

- アカウントは**ただちにロック**され、共有リンクや進行中の譲渡はすべて無効になります。
- **{{ p.deletion_grace_days }} 日間**は取り消すことができます：もう一度ログインして**復元**を選択してください。
- {{ p.deletion_grace_days }} 日が経過すると、アカウント、ログブックのバックアップ、添付ファイル、レシート、スキャンは当方のサーバーから**完全に削除**され、ログインアカウントも削除されます。災害復旧用バックアップ内のコピーは、その後さらに {{ p.backup_expiry_days }} 日以内に失効します。
- アカウントを削除しても、サブスクリプションは解約されません。Google Play または App Store で解約してください。これらのストアは独自に購入記録を保管しています。

スマートフォンからアプリを削除しても、削除されるのはスマートフォン上のコピーのみです。バックアップは、アカウントを削除するまで残ります。

## 情報の保存期間

| 情報 | 保存期間 |
|---|---|
| アカウントとログブックのバックアップ | アカウントを削除するまで保存し、その後 {{ p.deletion_grace_days }} 日を経て削除（バックアップのコピーはさらに {{ p.backup_expiry_days }} 日後に失効） |
| お客様が削除した個々の記録、車両、写真 | デバイスからはただちに、当方のサーバーからは 90 日以内に削除 |
| 共有リンクと譲渡リンク | 24 時間後に期限切れになるか取り消されるまで。その後は記録としてアカウントが削除されるまで保存 |
{% if p.crash_reporting != "" %}| クラッシュレポート | 最長 90 日 |
{% endif %}{% if p.analytics != "" %}| 利用統計 | {{ t.privacy.analytics_retention }} |
{% endif %}| サポートメール | 最後のメッセージから 12 か月 |

## セキュリティ

スマートフォン上のログブックは、ほかのアプリから読み取れない Motoor 専用ストレージに保存され、生体認証ロックを追加することもできます。Motoor がインターネット経由で送信するデータはすべて暗号化されます。共有リンクと譲渡リンクには推測できない長いランダムなコードを使用し、当方は各コードのフィンガープリント（ハッシュ値）のみを保存します。スマートフォン内のデータを守るため、PIN、指紋、顔認証でスマートフォンをロックしてください。

## お子様について

Motoor は車両を所有または管理する方を対象としており、{{ p.min_age }} 歳未満のお子様を対象としたものではありません。当方は、お子様の個人情報を故意に収集することはありません。お子様が当方に情報を提供したと思われる場合は、メールでご連絡ください。当該情報を削除します。

## 本ポリシーの変更

本ポリシーを変更した場合は、このページ上部の日付を更新します。変更が収集する情報や取り扱う事業者に影響する場合は、変更が有効になる前に Motoor のアプリ内でもお知らせします。
